---
name: حماية النسخ الاحتياطي
description: قاعدة الوصول إلى النسخ الاحتياطي والاستيراد والتصدير وإعادة ضبط بيانات المنصة
---

النسخ الاحتياطي والاستيراد والتصدير وإعادة ضبط جميع البيانات إجراءات إدارية حساسة، ولا ينبغي أن تظهر أو تكون متاحة إلا لحسابات `admin`. الموظف يحتفظ بباقي صلاحياته، لكن لا يرى روابط هذه الأقسام ولا يصل إليها عبر الرابط المباشر.

**Why:** تصدير البيانات قد يؤدي إلى تسريبها، والاستيراد أو إعادة الضبط قد يسببان فقدانًا واسعًا للبيانات؛ لذلك لا يكفي إخفاء الزر وحده.

**How to apply:** عند إضافة مسار جديد يتعامل مع نسخة المنصة أو تصدير/استيراد البيانات، اجعله admin-only في القائمة والحماية الموجهة، ولا تعتمد على إخفاء الواجهة فقط.
