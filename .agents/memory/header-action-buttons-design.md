# تطوير أزرار الهيدر وإجراءات الصفحة الرئيسية (Header Action Buttons Design)

تم تحديث الهوية البصرية لأزرار الإجراءات السريعة وأزرار لوحة التحكم في الهيدر والصفحة الرئيسية للتناغم مع لغة التصميم الفاخرة للعلامة التجارية.

## المعايير المعتمدة:
1. **زر لوحة التحكم:**
   - إزالة الإطار والوهج الأخضر/التركوازي واستبداله بلون كحلي فحمي ملكي مع لمسة ذهبية هادئة تتسق مع خلفية الموقع.
2. **أزرار الإجراءات السريعة (اعرض عقارك، خدمات التشطيبات، اطرح استفسارك):**
   - تصميم فحم راقٍ أفتح قليلاً من الخلفية، مع إطار ذهبي رملي فاخر (`#B99A68` / `amber-500/30`).
   - خطوط واضحة وأوصاف فرعية متباينة تحسن تجربة المستخدم بدون تشتيت بصري.
3. **أزرار تصفية البحث:**
   - توحيد أزرار البحث (الكل، للبيع، للإيجار) بتدرجات الفحم والذهب الملكي وإلغاء أي ألوان دخيلة كالأخضر الفسفوري أو التركوازي.
