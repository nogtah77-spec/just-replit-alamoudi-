# مزامنة مشاهدات العقارات السحابية ومنع التكرار (Cloud Views Sync & Loop Prevention)

تم اعتماد نظام سحابي موحد لمزامنة إجمالي مشاهدات كل عقار عبر جدول الإعدادات السحابية `site_settings` تحت مفتاح مخصص `__property_views_store__`، مع حماية صارمة لمنع التكرار اللانهائي للعدادات.

## المشكلة السابقة والحل الجذري:
1. **مشكلة الحلقة اللانهائية (Loop):**
   - كان عداد المشاهدات يتزايد بالآلاف أثناء فتح صفحة العقار بسبب استدعاء دالة التحديث داخل `useEffect` غير المحمي مع إعادة رسم المكونات (`re-renders`).
   - **الحل:** تم وضع حارس مزدوج:
     * مرجع محلي (`useRef`) يمنع زيادة المشاهدة أكثر من مرة أثناء وجود المكون في الذاكرة.
     * حارس جلسة (`sessionStorage`) بمفتاح `viewed_prop_${id}` لضمان أن الزيارة الواحدة في نفس الجلسة تحسب المشاهدة لمرة واحدة فقط.
2. **المزامنة العابرة للأجهزة (Cross-Device Sync):**
   - لتجنب اختلاف المشاهدات بين اللابتوب والجوال (مثل ظهور 4000 في اللابتوب وصفر في الجوال)، يتم قراءة وحفظ المشاهدات مباشرة في السحابة (`Supabase`).
   - عند فتح أي عقار من أي جهاز، تظهر نفس المشاهدات الحقيقية المحدثة فورًا.

## الملفات المسؤولة:
- `artifacts/alamoudi/src/pages/PropertyDetails.tsx` — الحماية عبر `useRef` و `sessionStorage`.
- `artifacts/alamoudi/src/context/DataContext.tsx` — وظائف `incrementPropertyViews` و مزامنة مخزن المشاهدات `__property_views_store__`.
