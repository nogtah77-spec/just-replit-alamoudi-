# معمارية إشعارات الويب وتكامل VAPID (Web Push Notifications Architecture)

تم بناء منظومة متكاملة لإشعارات الويب الدافعة المتوافقة كليًا مع الهواتف الذكية ومتصفحات الحواسيب (PWA Web Push)، مما يتيح للإدارة إرسال عروض وتنبيهات فورية تظهر على أجهزة العملاء حتى عندما يكون المتصفح مغلقًا.

## المكونات الأساسية:
1. **خادم وتشفير VAPID:**
   - استخدام معيار الويب `Web Push Protocol` بمفاتيح تشفير VAPID (العامة والخاصة).
   - توقيع حمولة الإشعار (`Payload`) وتوزيعها عبر نقاط نهاية متصفحات المستخدمين (Google FCM, Apple Push Service, Mozilla).
2. **تكامل Service Worker (v14):**
   - استقبال أحداث `push` في الخلفية وإظهار نافذة التنبيه الأصلية للهاتف أو النظام مع الشعار والأزرار.
   - التعامل مع حدث `notificationclick` لتوجيه العميل مباشرة إلى رابط العقار أو العرض الخاص.
3. **إدارة المشتركين في السحابة:**
   - حفظ اشتراكات المستخدمين (`PushSubscriptions`) في سحابة Supabase في جدول الإعدادات المعزول لاستدعائها عند الرغبة في إرسال بث جماعي أو مخصص.
4. **لوحة تحكم المدير للإشعارات:**
   - واجهة مخصصة للمدير لكتابة عنوان ونص ورابط الإشعار مع إمكانية إرسال إشعار تجريبي واختبار وصوله فوريًا.

## الملفات المسؤولة:
- `artifacts/alamoudi/src/lib/pushNotificationService.ts` — منطق الاشتراك، التشفير، وإرسال التنبيهات.
- `artifacts/alamoudi/src/components/common/PushNotificationPrompt.tsx` — نافذة طلب إذن الإشعارات الذكية للمستخدمين.
- `artifacts/alamoudi/src/pages/admin/PushNotifications.tsx` — لوحة الإدارة لإرسال وبث الإشعارات.
- `artifacts/alamoudi/public/sw.js` — معالج أحداث الـ Push والنقر في الخلفية.
