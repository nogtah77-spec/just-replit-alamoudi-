# معيار توحيد الأرقام الإنجليزية (English Numerals Standard 0-9)

تم اعتماد قاعدة معمارية صارمة بتوحيد كافة الأرقام المعروضة عبر منصة العمودي للتسويق العقاري لتكون بالأرقام الإنجليزية القياسية (`0-9` / `en-US`) ومنع استخدام الأرقام الهندية/المشرقية (`١، ٢، ٣`) أو تنسيق `ar-EG`.

## النطاق المطبق:
1. **الأسعار والمبالغ المالية:** جميع الأسعار تُنسق عبر `toLocaleString("en-US")` مع الرمز `ج.م`.
2. **العدادات والإحصائيات:** لوحة التحكم، عداد الزوار، العقود، الطلبات، الإعلانات، والحملات.
3. **التواريخ:** تُعرض أسماء الشهور باللغة العربية مع الأرقام الإنجليزية حصراً عبر التنسيق `ar-SA-u-nu-latn`.
4. **أكواد العقارات والأرقام الهندسية:** منع كتابة الأكواد بالأرقام المشرقية (مثل `B١٢`) واستخدام `B12` و `404` بدلاً من `٤٠٤`.

## الملفات المرجعية:
- كافة صفحات لوحة التحكم (`artifacts/alamoudi/src/pages/admin/*`).
- حاسبة التمويل (`MortgageCalculatorPage.tsx` & `MortgageReportModal.tsx`).
- مكونات الرسوم البيانية والإحصائيات (`chart.tsx`, `Analytics.tsx`, `AdAnalytics.tsx`).
