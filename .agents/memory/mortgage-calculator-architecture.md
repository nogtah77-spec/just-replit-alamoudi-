# معمارية حاسبة التمويل والأقساط (Mortgage Calculator Architecture)

تتضمن حاسبة التمويل العقاري في المنصة (`MortgageCalculatorPage.tsx`) منظومة حسابية متقدمة تدعم التخصيص الكامل لمدد السداد وتخزين الحالة الدائمة.

## الركائز المعمارية:
1. **التحكم الهجين في المدة (Hybrid Duration Controls):**
   - **أزرار الاختيار السريع (Presets):** تدعم كافة المدد بما فيها أنصاف السنوات (`0.5`، `1`، `1.5`، `2`، `2.5`، `3`، `3.5`... حتى `25` سنة).
   - **شريط التمرير (Slider):** بدقة `step={0.5}` لحرية السحب والانتقال السلس.
   - **أزرار الضبط الميكروية (+ / -):** لزيادة أو إنقاص المدة بمقدار نصف سنة (6 أشهر).
2. **المعالجة الحسابية للسنوات الكسرية (Fractional Amortization Schedule):**
   - تعمل الحلقة عبر `Math.ceil(loanYears)` وتوزيع الأشهر بدقة `Math.min(12, totalMonths - (year - 1) * 12)`.
   - عند اختيار سنة ونصف (`1.5` سنة = 18 شهراً)، تُحسب السنة الأولى (12 شهراً) والسنة الثانية كصف منفصل باسم `السنة 2 (6 أشهر)` برصيد نهائي 0 ج.م.
3. **التخزين الدائم للتصفير (Permanent State Persistence):**
   - تحفظ الحالة تحت المفتاح `alm_mortgage_calculator_state` في `localStorage`.
   - عند تصفير العدادات عبر نافذة التأكيد (`AlertDialog`)، تظل الخانات فارغة ومصفرة بصورة دائمة حتى بعد إعادة فتح المتصفح أو الانتقال بين الصفحات.
4. **تصدير تقرير PDF المباشر وتكامل واتساب:**
   - توليد وتنزيل فوري لتقرير مالي احترافي بدون فتح نافذة الطباعة الافتراضية عبر التقاط DOM مباشر، وتوليد رسائل واتساب مهيئة بكافة تفاصيل السداد.
