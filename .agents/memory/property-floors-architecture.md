# معمارية مواصفات العقارات والتحكم بعدد طوابق المبنى

## السياق والدافع
لاحظ المستخدم ظهور بند «عدد طوابق العقار: 1» تلقائياً في صفحة تفاصيل غالبية العقارات والشقق المضافة في المنصة، رغم أنه لم يحدد عدد طوابق المبنى أثناء إدخال العقار. وتسبب ذلك في مظهر غير دقيق للشقق، وتطلب حلاً جذرياً يصحح العقارات الحالية (69 عقاراً) بدون الحاجة للتعديل اليدوي، ويضمن عدم ظهور هذا البند مستقبلاً لأي عقار إلا إذا حُدد صراحة من قبل المستخدم، مع الإبقاء على الحقل متاحاً في لوحة التحكم.

## السبب الجذري
في ملف `artifacts/alamoudi/src/lib/supabaseService.ts`، كانت دالة تحويل صف قاعدة البيانات إلى كائن العقار (`rowToProperty`) تحتوي على سطر:
```typescript
floors: Number(r.floors) || 1
```
هذا السطر البرمجي كان يعتبر أي قيمة `0` أو غير محددة قيمة كاذبة (Falsy)، فيقوم قسراً بتحويلها إلى `1` وحفظها في الكاش، مما يتسبب في إظهارها في صفحة تفاصيل العقار كـ «عدد طوابق العقار: 1».

## القواعد والحلول المعمارية المعتمدة

### 1. إزالة القيمة الافتراضية القسرية
- تعديل السطر في `supabaseService.ts` ليصبح:
  ```typescript
  floors: Number(r.floors) || 0
  ```
  بحيث تظل القيمة `0` إذا لم تُحدد.

### 2. إخفاء البند شرطياً في صفحة تفاصيل العقار (`PropertyDetails.tsx`)
- تعديل شرط عرض عدد الطوابق ليصبح:
  ```typescript
  { label: "عدد طوابق العقار", value: Number(property.floors) > 0 ? property.floors : null }
  ```
- بفضل الفلترة اللاحقة `.filter(r => r.value != null && r.value !== "")`، يتم استبعاد السطر بالكامل تلقائياً إذا كانت القيمة `0` أو غير محددة، ولا يظهر إلا إذا كانت القيمة أكبر من الصفر قطعاً.

### 3. التحديث السحابي الشامل للعقارات الـ 69 دفعة واحدة
- تم تنفيذ سكريبت فوري على قاعدة بيانات Supabase الحية وتصفير حقل `floors = 0` لجميع العقارات الـ 69 الحقيقية.
- تم تصفير حقل `floors: 0` في ملف البذور الأساسي `seedProperties.ts` لجميع العقارات الـ 78.

### 4. تدقيق المحلل الذكي للإعلانات (`aiPropertyParser.ts`)
- تم تحسين التعبيرات النمطية (Regex) لاستخراج عدد طوابق المبنى بحيث تقتصر على الصيغ الدقيقة الصريحة (مثل: `عدد أدوار العمارة: 5` أو `عمارة 4 أدوار`)، ومنع أي خلط محتمل بين دور الشقة (الدور الأول) وعدد طوابق المبنى.

### 5. ترقية كاش المتصفح
- ترقية مفتاح الكاش المحلي في `DataContext.tsx` إلى `alm_cache_v6` لضمان تحديث الذاكرة لجميع الزوار على الفور دون بقاء أي أثر للبيانات السابقة.
