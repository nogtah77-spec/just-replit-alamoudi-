---
name: تحميل خلفية الدخول
description: قرار الأداء الخاص بعرض صفحة الدخول وخلفيتها قبل اكتمال بيانات المنصة.
---

صفحة الدخول تعتمد على إعدادات المنصة المخزنة مؤقتًا وتُعرض قبل اكتمال بقية بيانات التطبيق. صورة الخلفية المرفوعة تُعرض كعنصر صورة بأولوية تحميل عالية، مع تحديث الكاش فور حفظ الإعدادات.

**Why:** بوابة تحميل البيانات العامة كانت تؤخر ظهور صفحة الدخول وصورة الخلفية، وكان ذلك أوضح على الجوال.

**How to apply:** عند تعديل تحميل صفحة الدخول أو إعداداتها، حافظ على مسار العرض المبكر والكاش المحلي، ولا تجعل الصفحة تنتظر بيانات الإدارة أو القوائم العامة.
