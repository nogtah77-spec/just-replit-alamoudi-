---
name: Admin page header language
description: قاعدة تصميم صناديق العناوين في لوحة إدارة منصة العمودي
---

تستخدم صناديق عناوين لوحة الإدارة لغة بصرية مشتركة، لا قالبًا جامدًا: Midnight Blue مع Antique Brass، ارتفاع مختصر، حواف وإضاءة هادئة دون دوائر زخرفية أو توهجات شعاعية، RTL، وأزرار واضحة. يختلف كل صندوق في الأيقونة والشارة والوصف والإجراءات وفق طبيعة الصفحة.

**Why:** طلب المستخدم أن تبدو الصفحات من عائلة واحدة مع احتفاظ كل قسم بشخصيته المهنية، بدل تكرار صندوق واحد حرفيًا أو ترك عناوين قديمة متفاوتة.

**How to apply:** عند إضافة صفحة إدارية جديدة استخدم مكوّن العنوان المشترك، وخصص `title` و`subtitle` و`eyebrow` و`icon` و`actions`. لا تضف دوائر أو نصف دوائر كزخرفة خلفية. أبقِ الصفحات التفصيلية أو ذات الأدوات الكثيفة على تخطيطها الخاص إذا كان ذلك أوضح.
