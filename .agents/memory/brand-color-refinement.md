---
name: Alamoudi brand color refinement
description: لوحة ألوان الهوية المطورة بلون البيج الرملي التوب الدافيء (#A9927D)
---

تعتمد الهوية المطورة على Midnight Blue `#10202D` كلون أساسي، وWarm Sand Taupe `#A9927D` كلون إبراز وتمييز رئيسي، وHover State `#BBA591`، وBorder/Sub-accent `#C7B6A6`، مع Warm Ivory `#F5F3EE` للخلفيات الفاتحة، وكحلي ثانوي `#173044` للبطاقات الداكنة.

**Why:** تم استبدال الدرجة النحاسية السابقة بدرجة بيج رملي دافئ ملكي هادئ `#A9927D` لتعزيز الطابع المعماري الفاخر وتقليل حدة التوهج الأصفر/النحاسي، مع مراعاة كاملة لتباين WCAG القياسي في النسختين الداكنة والفاتحة.

**How to apply:** 
- استخدم دائماً النص الكحلي الداكن `#10202D` فوق الأزرار والشارات ذات الخلفية الرملية `#A9927D` لتحقيق نسبة تباين تتجاوز 5.4:1 (مطابقة لمعايير WCAG AA/AAA).
- للأطر والحدود الزجاجية الخفيفة استخدم `#C7B6A6` أو الشفافيات التناسبية `#A9927D/35` و `#A9927D/40`.
- للنصوص الإرشادية والفرعية الدقيقة على الخلفيات الداكنة استخدم `#DDD1C4` أو `#C7B6A6` لضمان قراءة مريحة بدون إجهاد للعين.
- لا تخلط بين الحالات الوظيفية الدلالية (نجاح، تحذير، خطأ) واللون الرملي الأساسي.
