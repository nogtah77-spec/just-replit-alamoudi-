أريد إنشاء صفحة جديدة مستقلة في لوحة التحكم باسم **"البانر الذكي"**، ولا تكون ضمن صفحة الإعلانات الحالية.

هذه الصفحة مخصصة لإنشاء وإدارة بانرات ديناميكية يمكن عرضها في أي مكان داخل المنصة.

يجب أن يدعم النظام إنشاء عدد غير محدود من البانرات مع:
- إنشاء وتعديل وحذف البانرات.
- ترتيب البانرات.
- تفعيل وتعطيل.
- معاينة مباشرة قبل النشر.
- تصميم Responsive.
- أداء عالي مع Cache لتقليل استهلاك الـ API.

أنواع البانرات المطلوبة:
- المباريات المباشرة.
- مباريات اليوم.
- نتائج المباريات.
- ترتيب الدوريات.
- الأخبار.
- الطقس.
- أسعار الذهب.
- أسعار العملات.
- عداد تنازلي احترافي.
- HTML مخصص.

بالنسبة لكرة القدم:
اعتمد موقع Football-Data.org كمصدر رسمي للبيانات، ولا تستخدم أي مصدر آخر إلا إذا طلبت ذلك مستقبلاً.

أنشئ في أعلى الصفحة قسم "إعدادات الخدمات"، بحيث يحتوي على إعدادات وربط جميع الخدمات الخارجية (APIs)، مع إمكانية اختبار الاتصال وحفظ الإعدادات.

إذا احتجت أي API أو API Key أو Token أو بيانات تسجيل، فلا تستخدم قيماً وهمية، بل اطلبها مني مباشرة.

اعتمد أفضل الخدمات المجانية فقط، ولا تستخدم أي خدمة مدفوعة.

==========================
العداد التنازلي (مهم جداً)
==========================

أريد أن يكون العداد التنازلي بمثابة مصمم Banner بسيط واحترافي، بحيث أستطيع إنشاء عداد تنازلي خاص بي بالكامل.

يجب أن أستطيع:

- رفع صورة خلفية بأي أبعاد، مع قص وتموضع وملاءمة الصورة بشكل احترافي.
- كتابة عنوان ووصف فوق الصورة.
- تغيير حجم النصوص.
- تغيير لون النصوص.
- تغيير شفافية النصوص.
- تغيير محاذاة النصوص.
- إضافة شعار (Logo) بخلفية شفافة، مع إمكانية تكبيره وتصغيره وتحريكه.
- إضافة طبقة Overlay فوق الصورة (غامق، فاتح، شفاف، ضبابي...).
- التحكم الكامل بتاريخ ووقت انتهاء العداد.

ولا أريد أن تضيف لي خطوطاً أو ملصقات أو إيموجيات بنفسك.

بل أنشئ فقط نظاماً يسمح لي مستقبلاً بإضافة:
- خطوط جديدة.
- ملصقات (Stickers).
- إيموجيات.

بحيث تكون المنصة جاهزة لهذه المزايا لاحقاً دون الحاجة لإعادة بناء النظام.

أريد أن يكون التنفيذ احترافياً، منظماً، وقابلاً للتوسع مستقبلاً.
